# StoicWare Business Management System

StoicWare is a complete business management and invoicing application.  
Features include:
- Dashboard with revenue overview  
- Customer management with transaction history  
- Quotes, invoices, and payments with VAT/discount support  
- Delivery notes and printable statements  
- Reports, notifications, and audit logs  
- Settings for company info, banking details, and document numbering  
- PDF/Print views for all documents
